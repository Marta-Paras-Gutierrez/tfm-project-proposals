# 📋 TFM Project Proposals

This repository contains the initial project proposals for my **Master's Final Project (TFM)** in **Data Science & Artificial Intelligence**.

The objective of this phase is to identify a real-world problem that can be addressed through data collection, processing, analysis and visualization, following a Minimum Viable Product (MVP) approach.

Rather than focusing on implementation, these proposals evaluate different project ideas based on their feasibility, potential impact and scalability before selecting the final project.

## 📌 Proposed Ideas

- **Archery Performance Analytics**
  - A data-driven platform for tracking and analyzing performance in archery competitions.

- **Opportunity Tracker**
  - A platform that centralizes academic opportunities such as scholarships, mobility programs and research calls.

- **Research Radar**
  - A platform for analyzing research trends, scientific publications and collaboration networks.

- **OpenData Explorer**
  - A platform for discovering and analyzing public open datasets from different official sources.
